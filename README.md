# EdTech Website

## Project Description

EdTech Website is a web-based educational platform developed to provide
users with access to educational courses and registration functionality.

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- PHP
- MySQL

## Main Features

- User registration
- User login
- Course management
- Course selection
- Edit and delete functionality
- MySQL database integration
- Responsive user interface
